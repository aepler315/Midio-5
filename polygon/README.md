# Midio Polygon

Standalone crystal-figure particle lattice. Midio is a standing gem — faceted
head, arm-shards, two feet — tessellated into an XPBD body with Delaunay
facets, Müller shape matching, four material modes, and a music-driven
conductor.

This directory is a separate TanStack Start app. It does not replace the
Super Maudio World game at the repo root.

```sh
cd polygon
npm install
npm run dev
```
